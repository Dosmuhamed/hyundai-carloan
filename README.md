# Hyundai — заявка на автокредит с отправкой в Telegram

Демо страницы https://hyundai.kz/ru/avtokreditovanie/. При открытии сразу появляется модальное окно. Пока клиент не оставит ФИО и телефон, страницу посмотреть нельзя. Каждая заявка сразу приходит менеджерам в Telegram через бота [@hyundai_fishing_bot](https://t.me/hyundai_fishing_bot):

```
🚗 Новая заявка на автокредит

👤 ФИО: Иванов Иван Иванович
📞 Телефон: +7 701 123 45 67
🕒 Время: 16.11.2026, 10:40
🌐 Страница: dosmuhamed.github.io/hyundai-carloan/?utm_source=…
```

Сайт полностью статический, сервер не нужен. Подходит для GitHub Pages.

## Публикация на GitHub Pages

```bash
git add .
git commit -m "Демо: заявка на автокредит Hyundai"
git push -u origin main
```

Затем на GitHub откройте **Settings → Pages**:

1. В **Source** выберите **Deploy from a branch**.
2. Укажите ветку **main** и папку **/ (root)**.
3. Нажмите **Save**.

Через 1–2 минуты сайт откроется по адресу `https://<логин>.github.io/hyundai-carloan/`.

## Настройки Telegram

Они в начале файла `assets/lead-modal.js`:

```js
var TELEGRAM_BOT_TOKEN = '…';             // токен бота от @BotFather
var TELEGRAM_CHAT_IDS = ['5416315021'];   // ID менеджеров через запятую
```

- **Добавить менеджера:** допишите его ID в список, например `['5416315021', '123456789']`. Каждый менеджер должен один раз открыть бота и нажать **Start**. Иначе Telegram не разрешит боту ему писать. Свой ID можно узнать у [@userinfobot](https://t.me/userinfobot).
- **Общий чат:** добавьте бота в группу менеджеров и укажите ID группы. Он начинается с `-100…`.
- Если до кого-то заявка не дошла, причина видна в консоли браузера (F12).

## ⚠️ Токен виден всем

На GitHub Pages нет сервера, поэтому токен бота лежит прямо в JS-файле. Его может прочитать любой посетитель через «Просмотр кода» и любой, кто откроет репозиторий. С токеном можно отправлять сообщения от имени бота всем, кто нажал у него Start, то есть заспамить менеджеров.

Для демо это допустимо. Для боевого сайта:

- **Перевыпустите токен.** В @BotFather отправьте `/revoke`, если токен утёк или демо больше не нужно.
- **Уберите токен со страницы.** Отправку нужно перенести на сервер: свой бэкенд hyundai.kz или бесплатный Cloudflare Worker. Страница отправляет заявку на сервер, а сервер с токеном пересылает её в Telegram.
